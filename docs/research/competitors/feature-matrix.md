# Матрица возможностей

Сравнение восьми продуктов по карточкам от 2026-11-04. MPSTATS добавлен в тот же день, после того как сайт снова открылся: 3 ноября он отвечал 403 и в семёрку не входил. Первый проход 2026-11-03 остаётся в [2026-11-03-kandidaty.md](2026-11-03-kandidaty.md) и не заменяется этой таблицей.

Личный кабинет не открывался. Статуса «Да» в ячейках нет: публичный текст подтверждает заявление, не работу расчёта. «Неизвестно» значит, что на открытых страницах сведения не нашлись. Это не вывод, что функции нет.

| Статус ячейки | Когда стоит |
| --- | --- |
| Заявлено | Конкурент написал об этом на официальной странице |
| Частично | Есть оговорка, противоречие страниц или описание не для всех площадок |
| Неизвестно | На открытых страницах этого прохода не найдено |
