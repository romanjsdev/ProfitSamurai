# Матрица возможностей

Сравнение подтверждённых возможностей. Колонки конкурентов добавляются только после заметки в `companies/` или прямой ссылки на первоисточник. Пустые ячейки означают, что исследования ещё нет, а не отсутствие функции.

Статусы ячейки:

| Статус | Когда ставить |
| --- | --- |
| Да | Возможность подтверждена |
| Заявлено | Конкурент написал о ней, работа не проверена |
| Частично | Есть только с ограничением |
| Нет | Отсутствие подтверждено |
| Неизвестно | Сведений недостаточно |

У заполненной ячейки в колонке «Источник» должна быть ссылка на заметку или первоисточник и дата проверки. Сейчас таких ячеек нет.
