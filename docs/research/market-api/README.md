# Исследования API Яндекс Маркета

Каталог ведёт `market-api-expert`. Здесь фиксируются методы, поля, ограничения частоты, даты, статусы, сроки формирования отчётов и изменения API. Формула прибыли в эти заметки не входит.

## Имя файла

`YYYY-MM-DD-kratkoe-imya.md`

Дата в имени — день исследования. Короткое имя описывает тему, а не номер задачи. Повтор той же темы получает новый файл. Старый файл не заменяется.

## Обязательные разделы

1. Источники.
2. Подтверждённые факты.
3. Гипотезы.
4. Ограничения.
5. Открытые вопросы.

В начале заметки укажи дату исследования и имя агента `market-api-expert`. Если у страницы документации есть дата или номер редакции, запиши их рядом с URL.

## Источники

Официальная страница Маркета — основной источник. Ссылка ставится на конкретный факт: метод, поле, лимит или статус. Рядом с URL укажи дату чтения.

Факт из кода или документа репозитория ссылается на путь и строки. Наблюдение по живым данным указывает отчёт, период и имена полей. Текст SELECT не должен содержать секрет.

Страница, которую не открывали в этом исследовании, сторонний SDK и память прошлого диалога остаются гипотезой, даже если раньше казались надёжными.

## Факты, гипотезы и противоречия

Подтверждённый факт имеет источник в этой же заметке. Гипотеза явно названа гипотезой и не формулируется как поведение API.

Открытый вопрос — то, чего нет в прочитанных источниках. Противоречие между двумя источниками или со старой заметкой записывается в «Открытые вопросы» либо в объяснении нового вывода. Новая заметка даёт относительную ссылку на предыдущую и пишет, какой вывод больше не действует и почему.

## Чего в каталоге нет

Ключи, токены, пароли, шифротекст, подписанные URL, персональные данные и полные файлы отчётов сюда не сохраняются.
