# ADR 0004. В базе только идентификаторы

## Статус

Принято

## Контекст

Ответ `GET /v2/campaigns` содержит домен, модель размещения, признак express, название бизнеса и другие поля. Пока ни одно из них не читается нашим API и не нужно, чтобы повторить этот же запрос.

## Решение

`cabinets` хранит `business_id` и шифротекст ключа. `campaigns` хранит `campaign_id` и `business_id`. Сырой JSON, имя, домен, модель размещения, статус синхронизации и время записи не добавляются.

Кампания без `business.id` пропускается. Если в ответе не осталось ни одного кабинета, `POST /cabinets` отвечает `422` и ничего не пишет. Один `campaign_id` принадлежит одному кабинету; если идентификатор встретился дважды, остаётся более поздняя строка ответа. Повторная синхронизация кабинета заменяет его набор кампаний: лишние строки этого `business_id` удаляются.

## Последствия

Модель размещения нельзя восстановить из базы, только новым вызовом `GET /v2/campaigns`. Кабинет, который исчез из ответа ключа, сам не удаляется: в этом ответе его больше нет, и мы не знаем, отозван доступ или страница просто его не вернула.
