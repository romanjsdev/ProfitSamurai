# ADR 0005. Api-Key хранится шифротекстом

## Статус

Принято

## Контекст

Повторить запрос к Маркету без Api-Key нельзя, поэтому ключ магазина сохраняется. Открытая строка в Postgres читается любым, у кого есть доступ к базе или к дампу.

## Решение

В `shops.api_key_ciphertext` пишется токен Fernet. Ключ шифрования задаётся `FERNET_KEY` и в базу не входит. На одно подключение магазина шифротекст считается один раз и записывается во все кабинеты, которые вернул этот ключ. Fernet недетерминированный: повторная запись того же Api-Key даёт другой ciphertext.

## Последствия

Без того же `FERNET_KEY` ключ из базы не прочитать. Смена `FERNET_KEY` делает уже записанные ciphertext нерасшифровываемыми, пока магазин не подключат заново.
