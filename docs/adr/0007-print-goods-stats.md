# ADR 0007. Отчёт по товарам печатается и не сохраняется

## Статус

Принято

## Контекст

`POST /v2/campaigns/{campaignId}/stats/skus` возвращает отчёт по товарам магазина: SKU, цену, категорию, склады, тарифы. В теле обязателен `shopSkus` (от 1 до 500 своих SKU). Сам по себе `campaign_id` список товаров не отдаёт.

SKU магазина лежат в `offerId` ответа `POST /v2/campaigns/{campaignId}/offers`. Эти идентификаторы нужны только как вход следующего запроса.

## Решение

`POST /cabinets` после записи идентификаторов для каждой кампании читает страницы товаров (`limit` 200, дальше `paging.nextPageToken`) и вызывает отчёт пачками по 500 `shopSkus`. Тело ответа Маркета печатается в stdout процесса API. В базу, в ответ нашего API и в файлы оно не пишется. `offerId` тоже не пишутся.

Если у кампании нет товаров, отчёт не вызывается и печатается строка, что предложений нет. Ошибка Маркета на этом шаге — `502`, уже записанные идентификаторы кабинета при этом остаются.

## Последствия

Поля отчёта в [модели данных](../data-model.md) не появляются. Повторный просмотр требует нового `POST /cabinets`. Утверждение ADR 0002, что Маркет вызывается только ради списка кампаний, для этого просмотра больше не действует.
