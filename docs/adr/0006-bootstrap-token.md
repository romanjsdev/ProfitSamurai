# ADR 0006. API закрыт одним bootstrap-токеном

## Статус

Принято

## Контекст

Маршруты клиентов принимают название компании или Api-Key магазина и записывают их в реестр. Без заслона любой, кто достучался до порта, может создать клиента или сохранить чужой ключ.

## Решение

Маршруты `/clients` требуют заголовок `X-Bootstrap-Token`. Ожидаемое значение — `BOOTSTRAP_TOKEN`. Сравнение постоянное по времени. Пустой токен в настройках — ответ `503`, и запрос к Маркету не уходит. Отсутствие заголовка или несовпадение — `401`.

## Последствия

Токен один на весь процесс. Это не изоляция клиентов. Отдельные пользователи потребуют нового решения, а не поля «чей это токен» в `shops`.
